# Elevate Labs DevOps Internship – Task 4

## Version-Controlled DevOps Project with Git

### Project Overview
This project demonstrates Git and GitHub version control practices as part of the Elevate Labs DevOps Internship.

### Objectives
- Understand Git version control.
- Implement branching strategies.
- Practice commits and pull requests.
- Resolve merge conflicts.
- Use Git tags for version management.

### Tools Used
- Git
- GitHub
- Visual Studio Code
- Python

| Branch | Purpose |
|---|---|

### Tasks Implemented
1. Initialized Git repository.
2. Connected local repository to GitHub.
3. Created main, dev and feature branches.
4. Practiced Git commits.
5. Created and merged Pull Requests.
6. Created and resolved merge conflicts.
7. Configured .gitignore.
8. Created and pushed Git tag v1.0.0.
